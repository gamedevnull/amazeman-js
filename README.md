# Amazeman 3D

---

Wolfenstein-style maze escape game in TypeScript.

Find keys, open doors, collect coins and escape the maze before time runs out.

![Textured](./res/screen.png)


### Controls

- Arrows – move and turn
- Space – start / open door
- M – toggle minimap
